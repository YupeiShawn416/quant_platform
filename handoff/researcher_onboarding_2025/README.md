# Researcher Onboarding Pack - 2025 MVP

## 1. What This Pack Is

This is the handoff pack for using Quant Platform MVP as a researcher.

Researchers use it to complete:

```text
API 拉数据 -> 本地生成策略权重 -> 打包 strategy_package.zip -> 上传服务器回测 -> 下载 result zip -> 写研究说明
```

## 2. Who Should Receive This

- 研究员
- 实习生
- AI agent 操作者

## 3. What To Send To Researchers

Send these files and folders:

- `00_READ_ME_FIRST.md`
- `01_DATA_USAGE_RULES.md`
- `02_SIMPLE_USER_MANUAL.md`
- `03_AI_AGENT_PROMPT.md`
- `04_SUBMISSION_REQUIREMENTS.md`
- `05_TROUBLESHOOTING.md`
- `06_RESEARCH_REPORT_TEMPLATE.md`
- `07_PLATFORM_INFO_TEMPLATE.md`
- `sample_strategy_project/`
- `agent_prompts/`

## 4. What Admin Must Fill Before Sending

Admin must fill or send separately:

- `<SERVER_URL>`
- `<API_TOKEN>` through a controlled channel only
- current supported data range
- deadline
- submission method

Do not write the token into these files. Send token separately, preferably as a
temporary token.

## 5. What Researchers Must Submit

- `strategy_package.zip`
- platform result zip
- short research note
- issue feedback
