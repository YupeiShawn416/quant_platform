# 提交要求

研究员必须提交：

1. `strategy_package.zip`
2. 平台 result zip
3. 研究说明，300-800 字
4. 使用的数据范围
5. 策略逻辑一句话说明
6. 主要指标：
   - `total_return`
   - `sharpe`
   - `max_drawdown`
   - `benchmark_return`
   - `excess_return`
   - `trade_count`
7. 遇到的问题

不要提交：

1. API token
2. 原始行情数据
3. parquet
4. 大量中间 csv
5. `.env`
6. 私人密钥
7. 未脱敏截图
