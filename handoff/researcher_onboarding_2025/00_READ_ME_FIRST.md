# 先读这个

你需要做的是：按步骤生成一个 `strategy_package.zip`，上传到平台回测，然后下载 result zip，
最后写一份简短研究说明。

你不需要理解平台底层，也不需要自己写回测引擎。

你只需要：

1. 设置服务器地址和 API token。
2. 进入 `sample_strategy_project/`。
3. 按顺序运行脚本。
4. 上传 zip。
5. 打开 Dashboard。
6. 下载 result zip。

数据只能用于内部学习、研究和回测，禁止外传。

不要把 API token、数据文件、结果明细上传到 GitHub、公开网盘、公开 AI 工具或社交平台。

如果你用 AI agent，把 `03_AI_AGENT_PROMPT.md` 复制给 agent。

如果你手动操作，看 `02_SIMPLE_USER_MANUAL.md`。
