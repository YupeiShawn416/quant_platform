# Submit Package Example

For real submissions, use a Strategy Package generated by
`templates/research_weights_template`.

Local development:

```bash
curl -F "file=@/tmp/my_first_strategy_package.zip" \
  http://127.0.0.1:8000/backtests/run-package
```

Server with token:

```bash
curl -H "X-API-Token: <your_token>" \
  -F "file=@/tmp/my_first_strategy_package.zip" \
  http://<server>/backtests/run-package
```

After upload:

```text
http://<server>/ui/backtests/current
```

Download the result zip from Dashboard if you need to keep the result. A later
backtest can overwrite current.
