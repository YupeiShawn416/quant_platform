# Submit Package Example

For real submissions, use a Strategy Package generated by
`templates/research_weights_template`.

## Environment

Server handoff:

```bash
export QUANT_PLATFORM_API_URL="http://39.106.218.30"
export QUANT_PLATFORM_API_TOKEN="<token_sent_securely>"
```

Local development:

```bash
export QUANT_PLATFORM_API_URL="http://127.0.0.1:8000"
export QUANT_PLATFORM_API_TOKEN="<your_local_token>"
```

Keep the token in environment variables. Do not put tokens in package zips,
scripts, notebooks, or Git-tracked files.

## Upload

Local development:

```bash
curl -F "file=@/tmp/my_first_strategy_package.zip" \
  "$QUANT_PLATFORM_API_URL/backtests/run-package"
```

Server with token:

```bash
curl -H "X-API-Token: $QUANT_PLATFORM_API_TOKEN" \
  -F "file=@/tmp/my_first_strategy_package.zip" \
  "$QUANT_PLATFORM_API_URL/backtests/run-package"
```

After upload:

```bash
curl -H "X-API-Token: $QUANT_PLATFORM_API_TOKEN" \
  "$QUANT_PLATFORM_API_URL/backtests/current/summary"

curl -H "X-API-Token: $QUANT_PLATFORM_API_TOKEN" \
  "$QUANT_PLATFORM_API_URL/backtests/runs?limit=10"
```

Save the returned `run_id`. A later backtest can overwrite `current`, so prefer
run-specific reads once you know the id:

```bash
curl -H "X-API-Token: $QUANT_PLATFORM_API_TOKEN" \
  "$QUANT_PLATFORM_API_URL/backtests/runs/{run_id}/summary"

curl -H "X-API-Token: $QUANT_PLATFORM_API_TOKEN" \
  "$QUANT_PLATFORM_API_URL/backtests/runs/{run_id}/download" \
  -o backtest_result.zip
```

Dashboard:

```text
http://39.106.218.30/ui/backtests/current
```
