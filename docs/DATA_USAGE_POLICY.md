# Data Usage Policy

本文件用于说明 quant_platform 中数据的内部使用边界。它不是法律意见，具体要求以公司制度、
项目管理要求和原数据源授权协议为准。

## 1. Allowed Use

平台数据仅供内部学习、研究、回测、教学和策略验证使用。允许的典型场景包括：

- 内部量化研究
- 策略原型验证
- 回测平台功能验收
- 内部培训和教学
- 内部研究报告撰写

## 2. Prohibited Use

禁止将以下内容外传：

- 原始行情数据
- API 返回的明细数据
- 本地 Parquet 文件
- 下载结果中的明细行情数据
- 未脱敏的回测明细、交易明细或持仓明细

禁止把平台 API 作为对外数据服务。禁止批量下载后转售、转发或共享给无权限人员。

禁止把平台数据上传到：

- 公开代码仓库
- 公开网盘
- 公开 AI 工具
- 未授权第三方服务
- 任何无法确认数据授权边界的外部系统

## 3. Token And Access

API token 只供本人或被明确授权的服务使用。禁止把 API token 交给他人，禁止写入公开仓库，
禁止粘贴到公开聊天、公开工单或公开文档。

如果怀疑 token 泄露，应立即通知管理员并轮换 token。

## 4. Reports And External Sharing

研究报告如需对外展示，必须先做脱敏处理，并确认不违反原数据源授权、公司制度和项目管理要求。
报告中不应包含可反推出原始行情明细的大表、逐笔下载数据、完整股票池明细或未授权的原始数据片段。

## 5. Original Data Source Constraints

平台数据受原数据源授权约束。使用者必须遵守原数据服务商协议，不得绕过授权限制，不得扩大数据
使用范围，不得将内部平台包装成新的对外数据分发渠道。

## 6. Audit And Monitoring

管理员可以记录 API 使用日志，用于安全审计、异常排查、额度管理和平台稳定性维护。异常的大规模
请求、并发请求或疑似数据搬运行为可能被限制或暂停。

## 7. Ask First

如果不确定某种使用、外发、共享或上传行为是否允许，必须先询问管理员。默认规则是：

```text
不确定，就不要外发。
```
